# gamebackup 设计

日期：2026-08-24  
状态：已确认，可实现

## 一句话

Windows 桌面托盘应用：用户手动选择存档文件夹，每个文件夹独立进入版本管理；用隐藏 git 仓库保存历史，主界面用树形图查看存档线、回档、开新线。

## 目标用户与原则

- 给普通玩家，打开就能用，不要求会 git。
- 界面用「存档线 / 版本 / 恢复 / 标签」，不出现 commit、checkout、merge、HEAD、仓库等词。
- 尽量图形操作：点选、双击、右键。不提供命令行。
- 用户无需安装 Git、.NET、Node、Python。安装包约 10MB 级（Tauri + 系统 WebView2）。
- 代码注释用中文。

## 非目标（第一版不做）

- Steam 自动扫库
- 云同步、账号、远程 git
- 存档内容合并、行级 diff
- 拖拽建线、rebase、stash
- 自动关闭 Steam 云存档
- 安装向导、复杂主题

## 产品形态

- Windows 10/11 x64 桌面应用（Tauri 2）。
- 托盘常驻：备份中 / 已是最新 / 失败。右键：打开主窗口、暂停全部备份、退出。
- 主窗口：左侧已管理的文件夹列表，右侧当前项的树形图。
- 开机启动：设置里一个勾，默认关。
- 备份间隔：默认 1 分钟，设置可改。没改动则跳过提交。

## 上手流程

1. 打开后主按钮是「选择存档文件夹」。
2. 选中后立刻：起显示名（默认文件夹名，可改）、做第一次备份、开始监控、打开该文件夹的树形图。
3. 可继续添加多个文件夹。每份存档独立时间轴、独立隐藏 git 仓库。
4. 第一次不询问备份路径、间隔、开机启动。默认：备份根目录 `%LOCALAPPDATA%\gamebackup`，间隔 1 分钟。

## 多文件夹与命名

- 一份存档 = 一个被监控的文件夹。
- 应用同时管理多个文件夹，互不影响。
- 列表显示用户起的名字，不是磁盘文件夹名。添加时可改，之后列表右键可改名。
- 改名不改真实路径，不改 git 仓库目录名（仓库用内部 id）。
- 允许显示名重复；名字下方显示路径缩略。

## 主界面（SourceTree 风格，图形操作）

- 左侧：存档线列表。当前线高亮。点击一条线，图滚动到该线。
- 中间：树形关系图。圆点是一版，线是分叉。当前线加粗高亮，当前节点标「当前」。
- 单击节点：选中，侧栏显示时间、备注、改过的文件名（只列文件名，不做内容 diff）。
- 双击节点 = 默认恢复（另开一线）。
- 右键节点：恢复（另开一线）、覆盖恢复（确认）、从这里开新线、打标签、改备注。
- 右键左侧存档线：改名、删除线（确认；删的是线，不是游戏文件夹）。
- 顶部按钮：开新线、恢复、暂停备份。未选中节点时恢复类按钮不可用。
- 开关「显示自动备份」：默认关。

### 隐藏自动备份时仍显示

- 每条存档线的最新节点
- 用户打过的标签
- 开新线的起点
- 改过备注的节点
- 非自动备份节点

自动备份后台照常进行，只是默认不画出来。打开开关后，自动节点用更小、更淡的样式。

## 存储布局

三块互不掺和：

1. **游戏存档目录**：用户选的文件夹。只复制进出，**永不写入 `.git`**。
2. **备份根目录**：默认 `%LOCALAPPDATA%\gamebackup`，设置可改。
   - `config.json`：已管理项、显示名、路径、当前线、是否暂停、间隔。
   - `repos/<id>/`：该存档的 git 仓库（工作区 + `.git`）。
3. **应用配置**：与备份根在一起。

不把游戏目录当成 git 工作区。不要求用户安装 Git，用 libgit2（Rust `git2`）。

## 核心流程

### 检测改动

每分钟（或用户设定间隔）对每个未暂停且路径可用的文件夹：根据「相对路径 + 大小 + mtime」做指纹。与上次已提交指纹相同则跳过。

### 自动备份

指纹变化则：把游戏目录同步复制进对应 `repos/<id>/`（先清掉工作区里游戏侧已删除的文件），再提交。提交信息带 `[auto]` 前缀，便于图上隐藏。

启动后对每个已管理文件夹立刻做一次检测（不必等下一分钟）。

### 开新线

从选中版本创建 git 分支。用户可命名；默认「线-时间」。

### 恢复（默认：另开一线）

1. 若当前游戏目录相对当前线有未备份改动，先做一次自动备份。
2. 从当前线头创建新线（「恢复前-时间」），保住当前进度。
3. 从目标版本创建或切到一条线，把该版本文件复制回游戏目录。
4. 图上当前线切到目标这条。

### 覆盖恢复

二次确认后：不另开「恢复前」线，把目标版本复制回游戏目录，当前线移到该版本。

### 打标签 / 备注

标签用 git tag。备注写在提交说明里（改备注即 amend 仅限尚未被其他操作依赖时；更稳妥：用 git notes 存用户备注）。第一版用 git notes 存备注，自动提交无 notes。

## 出错处理

- 文件夹消失或不可访问：该项标红「路径不可用」，暂停该项，其它继续。路径恢复后自动继续。
- 文件被占用：本次跳过并记日志，下一轮再试，不连弹窗。
- 磁盘满或无写权限：托盘提示，停止写入，避免写坏仓库。
- 回档失败：游戏目录保持回档前状态（先拷到临时目录再替换，或复制失败则中止）。
- Steam 云：回档确认框附一句「若开启了云存档，Steam 可能再次覆盖」。不做自动关闭云。

## 技术选型

- Python 3.11 + 系统 WebView2（`pywebview`）画界面，`pystray` 托盘。不引入 Electron。
- git：`dulwich`（纯 Python，用户不用装 Git）。
- 树形图：前端根据仓库节点与父节点用 SVG 自绘。
- 打包：PyInstaller，用户无需安装 Python / Git / .NET。安装包大约 20–40MB（比 Tauri 略大，但这台开发机没有 Rust/MSVC，无法编 Tauri；界面仍是 WebView2，以后可再迁）。
- 开机启动：写入当前用户的「启动」快捷方式或注册表 Run 项。

## 测试

- Rust：指纹是否变化、自动提交判定、隐藏自动节点后的图数据（线头/标签仍在）、复制失败不破坏目标目录。
- 手工：添加两个文件夹、自动备份、隐藏自动点、开线、默认恢复、覆盖恢复。

## 默认值

| 项 | 值 |
|---|---|
| 备份根目录 | `%LOCALAPPDATA%\gamebackup` |
| 间隔 | 60 秒 |
| 显示自动备份 | 关 |

| 默认恢复 | 另开一线 |
